# 🚀 DigiTools - Premium Digital Marketplace

DigiTools is a high-performance, modern web application designed for creators and professionals. It features a curated collection of digital tools with a focus on seamless user experience, interactive animations, and a polished brand identity.

---

### 📝 Project Description
This project was built to solve the need for a clean, fast, and responsive digital products storefront. It features a dynamic product grid, an integrated cart system, and an interactive pricing table, all wrapped in a premium dark-themed aesthetic.

---

### 🛠️ Technology Stack
The project leverages the power of modern frontend tools to deliver a smooth and scalable interface:

* **React.js**: Powering the component-based architecture and state management (Tabs, Cart, Models).
* **Tailwind CSS**: Used for all styling, custom linear gradients, and responsive layouts.
* **Lucide React & React Icons**: For high-quality, scalable iconography.
* **React Toastify**: For elegant, real-time user notifications when managing the cart.

---

### ✨ Key Features

* **Interactive Sliding Navigation**: A custom-engineered tab system with a smooth sliding background animation that transitions between "Products" and "Cart" views.
* **Live Cart Integration**: A functional shopping cart featuring a real-time notification badge on the navigation bar, dynamic total price calculation, and instant item removal.
* **Premium Hover & Click Effects**: Cards feature a "floating" lift effect (`hover:-translate-y-3`) and buttons utilize tactile feedback (`active:scale-95`) to create a physical, high-end feel.
